# Projeto 3 — Análise Estatística de E-commerce

## Descrição

Este projeto utiliza Python para analisar dados de produtos de e-commerce e apresentar visualizações interativas em uma aplicação web desenvolvida com Dash e Plotly.

### Gráficos

Histograma da distribuição dos preços.

Gráfico de dispersão entre preço e nota.

Mapa de calor das correlações.

Gráfico de barras com as 10 marcas mais frequentes.

Gráfico de pizza com a distribuição por gênero.

Gráfico de densidade dos preços.

Gráfico de regressão entre número de avaliações e preço.

### Tecnologias utilizadas

Python

Pandas

NumPy

Plotly

Dash

SciPy

### Como executar

Instale o Python.

Instale as dependências executando pip install -r requirements.txt.

Deixe o arquivo ecommerce_estatistica.csv na pasta do projeto.

Execute python projeto.py.

Abra no navegador o endereço local indicado no terminal, normalmente http://127.0.0.1:8050/.

### Arquivos

projeto.py: código-fonte da aplicação.

ecommerce_estatistica.csv: conjunto de dados utilizado, caso sua distribuição seja permitida.

requirements.txt: dependências necessárias.
