# Projeto 3 — Análise Estatística de E-commerce

## Descrição

Este projeto utiliza Python para analisar dados de produtos de e-commerce e apresentar visualizações interativas em uma aplicação web desenvolvida com Dash e Plotly.

### Gráficos

Histograma da distribuição dos preços.

Gráfico de dispersão entre preço e nota.

Mapa de calor das correlações.

Gráfico de barras com as 10 marcas mais frequentes.

Gráfico de pizza com a distribuição por gênero.

Gráfico de densidade dos preços.

Gráfico de regressão entre número de avaliações e preço.
